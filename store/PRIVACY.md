# JobBid Autofill: privacy policy

_Last updated: 7 November 2026_

JobBid Autofill helps a recruiting team fill job applications for the candidates it represents.

## What the extension handles

- **Candidate profiles:** name, contact details, work history, education, resume files, saved answers to application questions, and (optionally) answers to voluntary equal-opportunity questions.
- **Application records:** job title, company, link, date and status of each application.
- **The form on the page being filled:** the questions and choices, so they can be answered.

## Where it goes

- **The user's computer:** stored in Chrome's extension storage.
- **The team's own JobBid Hub server:** the address the user signs in to. The team that runs the server controls this data. It is not sent to the extension's developer.
- **The AI provider the team chose** (for example Google Gemini or OpenAI), using the team's own API key, only when an answer is generated with AI. Only the question, its choices, and the profile and job details needed for the answer are sent.
- **IP lookup services** (ipwho.is, ipapi.co, ipify): only the request itself, to show the user's public IP and country.

No data is sold, used for advertising, or shared with anyone else.

## Candidates' rights

Candidates can ask the team that represents them to see, correct or delete their data. Deleting a profile in the JobBid Hub (with "erase all their history") removes the profile, the resume files, the application records and the fill reports. Copies in the hub's backups are removed as backups age out (14 days by default).
